01 · Ask

It sees what you see.

Press the hotkey, type a question. Optix grabs a screenshot of your active window and streams the answer back.

  • No actions, no file access
  • Visual overlay highlights
  • Web search across all modes

02 · Access

It does what you ask.

Switch to Access and Optix becomes an agent. It clicks, types, runs commands, and reads files.

  • Per-action or per-task approvals
  • Workspace folder boundary
  • USD cost ceiling per run

03 · Automate

It works how you work.

Run a task once with Record on. Optix saves it as a routine you can replay later in any prompt with /OA-N.

  • Anchored to UIA + window titles
  • Survives layout shifts
  • One-tap replay

Privacy & control

Your machine. Your data. Your call.

Optix is built so the trust model is auditable end-to-end.

●

Privacy pause

Toggle off screen capture for sensitive work. The agent runs blind without crashing.

⏷

Workspace boundary

The agent can read/write inside the workspace folder you set; anything outside always asks for approval.

$

Cost ceiling

Set a USD cap per Access run. Optix stops the loop if estimated spend crosses it.

≡

Audit log

Every Access run saves as inspectable JSON with messages, turns, actions, per-turn token usage, and exact cost.

⌧

Per-action approvals

Choose a per-action gate, a single per-task gate, or just trust it inside the workspace.
