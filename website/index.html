Desktop AI assistant

An AI teacher that sees, answers, acts, automates.

Three modes

One widget, three depths of involvement.

Switch with a tab. Each mode is more capable than the last — and more locked-down by default.

01

Ask

Single-shot Q&A over a screenshot of your active window. No actions, no file access. The safest place to start.

  • Streamed answers
  • Visual overlay highlights
  • Conversation memory (optional)
02

Access

Full agent loop. Optix can click, type, scroll, drag, run shell commands, list and read files, search the web, and ask clarifying questions.

  • Per-action or per-task approvals
  • Workspace folder boundary
  • USD cost ceiling per run
03

Automate

Access plus recording. Run a task once with the Record toggle on and it gets saved as a routine you can replay later by typing /OA-N in any prompt.

  • Semantic anchors (UIA + window titles)
  • Survives layout shifts
  • One-tap replay

How it works

It sees what you see.

OPTIX
1

Press the hotkey.

Default Ctrl + Shift + Space (⌘ + Shift + Space on macOS). The widget appears floating over whatever you're doing.

2

Type a question or task.

Optix grabs a screenshot of your active window and sends it to the model along with your prompt. The widget hides itself from its own captures, so the analysis is clean.

3

Watch it work.

In Ask mode, the answer streams back. In Access, it asks for approval before each action. In Automate, it records the whole flow as a one-tap replay.

Privacy & control

Privacy pause
