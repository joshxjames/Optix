Privacy-first design

AI Teacher Desktop is built with auditable controls, transparent data handling, and user-controlled retention.

  • Retention settings: Planner routing, OCR telemetry, and incident bundles all have adjustable retention windows.
  • Local-only default: The assistant can run in local-only mode, with no data sent to remote servers.
  • Activity timeline: See recent privacy-relevant actions such as settings changes and purges.
  • Exportable audit reports: Download JSON or Markdown privacy reports for internal review or support.
