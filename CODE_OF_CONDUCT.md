# Code of Conduct

The Optix project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

The full text of the covenant lives at the link above and is the
authoritative source. By participating in this project — opening issues,
submitting pull requests, joining discussions — you agree to follow it.

## Quick summary

The covenant boils down to a small set of expectations:

- **Treat people with respect.** Disagree on technical matters; don't
  attack the person.
- **Welcome contributors of every level of experience.** A clear, kind
  answer to a beginner question is worth more than the same answer
  delivered with attitude.
- **Assume good faith.** People have different backgrounds, time zones,
  English-fluency levels, and contexts. Read the most generous
  interpretation first.
- **Keep it on-topic.** Project spaces are for the project. Take
  unrelated debates elsewhere.

## Scope

This applies to all project spaces:

- The [GitHub repository](https://github.com/joshxjames/Optix) — issues,
  pull requests, discussions, code review comments, commit messages.
- Any official project channel (chat, video, etc.) that may exist now
  or in the future.
- Project-related interactions in public spaces when an individual is
  representing the project.

## Reporting

If you see behaviour that violates the covenant, please report it via
either:

- **A private security-style advisory** at
  [GitHub Security Advisories](https://github.com/joshxjames/Optix/security/advisories/new)
  — appropriate when discretion matters.
- **A direct issue** if the situation is straightforward and public
  visibility helps.

Reports will be reviewed by the project maintainers and acted on
in line with the covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
